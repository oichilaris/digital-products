# AI Prompt Pack: Business Growth Arsenal

## 20 ChatGPT/Claude Prompts for Solopreneurs & Small Business Owners

### Category: Marketing & Sales

#### Prompt 1: Cold Email Writer
```
You are an expert B2B cold email copywriter. Write a cold email for [PRODUCT/SERVICE] targeting [TARGET AUDIENCE].

Requirements:
- Subject line: under 50 characters, curiosity-driven, no spam words
- Opening: personalized hook based on [PROSPECT DETAIL]
- Body: 3-4 sentences max, focus on one specific pain point
- CTA: low-friction (question, not meeting request)
- Tone: professional but human, not salesy
- Include: social proof hint, one specific metric

Output format:
Subject: [subject]
Body: [email body]
Follow-up (Day 3): [follow-up email]
```

#### Prompt 2: Social Media Content Calendar
```
Create a 30-day social media content calendar for [BUSINESS/NICHE].

For each day provide:
- Platform (Instagram/LinkedIn/Twitter/TikTok)
- Content type (carousel, reel, text post, story)
- Hook/headline (attention-grabbing, under 10 words)
- Key message (one sentence)
- CTA
- Best posting time

Mix content types: 40% educational, 30% behind-the-scenes, 20% promotional, 10% engagement/UGC.

Output as a table: Day | Platform | Type | Hook | Message | CTA | Time
```

#### Prompt 3: Landing Page Copy
```
Write high-converting landing page copy for [PRODUCT/SERVICE].

Structure:
1. Hero Section: Headline (benefit-driven, under 8 words), Subheadline (what + who + how), CTA button text
2. Problem Section: 3 pain points the target audience faces
3. Solution Section: How your product solves each pain point
4. Features: 4 key features with benefit-focused descriptions
5. Social Proof: 3 testimonial templates (name, role, quote)
6. FAQ: 5 common objections with rebuttals
7. Final CTA: Urgency + guarantee + button

Tone: confident, clear, no jargon. Target: [AUDIENCE]
```

#### Prompt 4: Product Description (E-commerce)
```
Write an SEO-optimized product description for [PRODUCT].

Include:
- Title: [Primary Keyword] + [Benefit] (under 60 chars)
- Meta description: 150-160 chars with keyword
- H1: Product name
- Opening: 2 sentences highlighting main benefit
- Bullet points: 5 key features → benefits
- Story section: 3 sentences about use case
- Specifications: table format
- CTA: urgency-driven

Keywords to include: [KEYWORD1], [KEYWORD2], [KEYWORD3]
```

#### Prompt 5: Ad Copy (Facebook/Instagram)
```
Write 5 variations of Facebook/Instagram ad copy for [PRODUCT/SERVICE].

For each variation:
- Primary text (125 chars max, hook in first 3 words)
- Headline (40 chars max)
- Description (30 chars max)
- CTA button recommendation
- Target audience suggestion

Angles to use:
1. Problem → Solution
2. Social proof / testimonial
3. Curiosity / question
4. Urgency / scarcity
5. Benefit-driven / transformation

Include: emoji usage (1-2 per ad), no ALL CAPS, clear value proposition.
```

### Category: Content Creation

#### Prompt 6: Blog Post Outline
```
Create a comprehensive blog post outline for: "[TOPIC]"

Target keyword: [KEYWORD]
Target audience: [AUDIENCE]
Word count target: [1500-2500]

Structure:
- Title (SEO-optimized, under 60 chars)
- Meta description (150-160 chars)
- Introduction (hook + problem + promise)
- 5-7 H2 sections with 2-3 H3 subsections each
- Key points per section (3-5 bullets)
- Conclusion with CTA
- FAQ section (5 questions)
- Internal/external link suggestions

Include: statistics to research, expert quotes to find, images to create.
```

#### Prompt 7: YouTube Script
```
Write a YouTube video script for: "[TOPIC]"

Target length: [5-10] minutes
Style: [Educational/Entertaining/Review]

Structure:
- Hook (first 5 seconds): pattern interrupt + promise
- Intro (15 seconds): credibility + what they'll learn
- Main content: 3-5 key points with examples
- Story/case study (optional)
- CTA: subscribe + comment + next video
- Outro: recap + end screen

Include: B-roll suggestions, on-screen text, timestamps.
Tone: conversational, energetic, not robotic.
```

```
Subject line: [compelling, under 50 chars]

Sections:
1. Hook (personal story or insight) - 2-3 sentences

3. Quick wins (3 actionable tips) - bullet points
4. Resource/tool recommendation (with affiliate link placeholder)

```

#### Prompt 9: Twitter/X Thread
```
Write a Twitter/X thread about [TOPIC].

Format:
- Tweet 1 (hook): Bold claim or surprising stat, end with "🧵" or "Thread:"
- Tweets 2-8: One idea per tweet, 200-280 chars each
- Each tweet: standalone value + connection to next
- Include: 1-2 data points, 1 personal anecdote, 1 actionable tip

```

#### Prompt 10: Product Review
```
Write an honest, SEO-optimized product review for [PRODUCT].

Structure:
- Title: [Product Name] Review: [Verdict] ([Year])
- Verdict box: Rating (X/10), Best for, Not for, Price
- Introduction: What it is, who it's for
- Pros: 5 specific advantages
- Cons: 3 honest drawbacks
- Features deep-dive: 4 key features with real usage
- Comparison: vs top 2 competitors (table)
- Pricing: plans breakdown
- Who should buy: 3 audience types
- Final verdict: 2-3 sentences
- Affiliate disclosure

Tone: objective, detailed, trustworthy. Word count: 1500-2000.
```

### Category: Business Operations

#### Prompt 11: Business Plan Generator
```
Create a lean business plan for [BUSINESS IDEA].

Sections:
1. Executive Summary (50 words)
2. Problem & Solution (3 sentences each)
3. Target Market (demographics + psychographics)
4. Competitive Analysis (3 competitors, SWOT)
5. Revenue Model (pricing, channels, projections)
6. Marketing Strategy (3 channels, budget allocation)
7. Operations (team, tools, processes)
8. Financials (startup costs, break-even, 12-month projection)
9. Risks & Mitigation (top 3)
10. Milestones (30/60/90 day goals)

Format: structured, actionable, no fluff. Include specific numbers.
```

#### Prompt 12: SOP Creator
```
Create a Standard Operating Procedure for: [PROCESS/TASK]

Format:
- Title: [Process Name] SOP
- Purpose: one sentence
- Scope: who does this, when
- Prerequisites: tools/accounts needed
- Steps: numbered, each with:
  - Action (imperative verb)
  - Details (specific instructions)
  - Screenshot placeholder [IMG: description]
  - Time estimate
- Quality checklist: 5 verification points
- Troubleshooting: 3 common issues + fixes
- Revision history table

Make it foolproof for a new hire.
```

#### Prompt 13: Customer Persona
```
Create a detailed customer persona for [PRODUCT/SERVICE].

Include:
- Name & demographics (age, location, income, job)
- Psychographics (values, fears, goals, frustrations)
- Day in the life (morning to evening routine)
- Pain points (top 3, with emotional impact)
- Buying triggers (what makes them purchase)
- Objections (top 3 + rebuttals)
- Where they hang out (platforms, communities)
- Content they consume (podcasts, blogs, influencers)
- Watering holes (forums, groups, hashtags)
- Budget range for this solution

Make it specific and realistic, not generic.
```

#### Prompt 14: Pricing Strategy
```
Develop a pricing strategy for [PRODUCT/SERVICE].

Analyze:
1. Cost-based: calculate COGS + overhead + margin
2. Value-based: what's the perceived value to customer?
3. Competitor-based: what do competitors charge?
4. Psychological: charm pricing, anchoring, decoy effect

Recommend:
- 3 pricing tiers (Starter/Pro/Enterprise) with features
- Annual vs monthly discount
- Free trial vs freemium
- Launch pricing strategy (early bird, beta)
- Price increase timeline

Include: price elasticity estimate, willingness-to-pay research method.
```

#### Prompt 15: Competitor Analysis
```
Analyze competitors for [PRODUCT/SERVICE] in [MARKET].

For each competitor (top 5):

- Product features (comparison table)
- Pricing (all tiers)
- Strengths (3)
- Weaknesses (3)
- Marketing channels

Output: competitive matrix + 3 strategic recommendations.
```

## Bonus: Prompt Usage Tips

1. **Always provide context** - The more specific your inputs, the better the output
2. **Iterate** - First draft is rarely perfect, refine with follow-up prompts
3. **Chain prompts** - Use output from one prompt as input to another
4. **Set constraints** - Word limits, tone, format requirements
5. **Use examples** - Show the AI what "good" looks like

## How to Use This Pack

1. Copy the prompt you need
2. Replace [BRACKETED] placeholders with your specifics
3. Paste into ChatGPT, Claude, or any LLM
4. Review and refine the output
5. Save your best outputs for future reference
